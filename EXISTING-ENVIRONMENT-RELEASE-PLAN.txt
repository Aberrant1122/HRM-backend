Rollback and sign-in
Prefer a forward fix retaining sessionVersion and trigger. Old auth code removes protections even if counters remain, so an old-code rollback is a security-risk incident decision. Manager widening has a non-contracting down path. Dropping/recreating counters or restoring an older snapshot may resurrect tokens with the same signing key: rotate the secret before serving traffic in that recovery case. A restore loses post-checkpoint writes and requires its own reviewed recovery decision. Retain backup/volume references and reconcile data after recovery.
